# Mahammad İstifadə Təlimatı / Usage Guide

Mahammad AI Tutor yerli Ollama modelləri üzərində tam məxfi və oflayn işləyən fərdi repetitor tətbiqidir.

## Rejimlər və Funksiyalar

### 1. Mövzu İzahı (Explain a Topic)
- Sol paneldən təhsil səviyyənizi (Məktəb, Yuxarı sinif, Bakalavr, Magistr/Doktorantura) və fənni seçin.
- Aşağıdakı söhbət qutusuna istənilən mövzunu və ya sualı daxil edin.
- Süni intellekt repetitoru sizə addım-addım, aydın analoqlar, nümunələr və əsas xülasə ilə izah verəcəkdir.

### 2. Test Yaratmaq (Generate a Quiz)
- Sol menyudan "Generate a Quiz" rejimini seçin.
- Mövzunu və sualların sayını daxil edərək "Generate Quiz" düyməsini sıxın.
- Çoxseçimli (MCQ) sualları cavablandırın və "Submit Quiz" düyməsinə klikləyin.
- Sistem avtomatik nəticənizi hesablayacaq və hər bir cavab üçün ətraflı izahat təqdim edəcək.
